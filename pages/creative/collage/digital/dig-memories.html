Memory Collage

Using whatever photo-editing software you have on whatever device, make a collage of the memory to highlight what makes that person/place/moment special. Add other photos that represent it if you wish

Ideas

  • Memory of someone special, highlighting their personality
  • Memory of a place you've visited, highlighting what is unique there
  • Memory of an event you've been a part of, highlighting the fun moments
Do not worry about making it perfect! Just create and have fun! :)
