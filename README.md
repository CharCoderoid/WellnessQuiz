# Wellness Quiz 
A quiz that gives users an activity to do that will help them feel better about themselves

This was originally for the Technology For Wellness hackathon but unsubmitted due to time restraints. But I decided that I would work on it even after the hackathon. The project definitely was harder than it seems and allowed me to learn to manage my time better.
